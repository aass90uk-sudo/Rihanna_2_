# الناشر الإسلامي التلقائي لقناة تيليجرام

بوت تيليجرام غير متزامن مكتوب بلغة Python، ينشئ محتوى إسلامياً باللغة العربية وينشره تلقائياً في قناة `@Athar_Dz_Islamic`.

ينشر البوت أول منشور مباشرة بعد التشغيل، ثم ينشر المنشورات العامة كل 3 ساعات والمحتوى الإسلامي الدزايري كل ساعتين ونصف، مع تذكير يومي بقيام الليل عند الساعة 2:00 حسب المنطقة الزمنية المضبوطة.

## المميزات

- نشر المنشورات العامة تلقائياً كل 3 ساعات.
- نشر محتوى إسلامي دزايري بلهجة عاصمية مفهومة تلقائياً كل ساعتين ونصف.
- نشر تذكير بقيام الليل يومياً عند الساعة 2:00 فجراً.
- نشر أول منشور مباشرة بعد تشغيل البوت.
- إنشاء محتوى عربي باستخدام Groq.
- اختيار نوع المحتوى بشكل عشوائي، مثل:
  - آيات قرآنية.
  - أحاديث صحيحة.
  - أدعية.
  - أذكار.
  - تذكيرات إسلامية.
  - الرحمة.
  - المحبة في الإسلام.
  - حسن الأخلاق.
  - الصبر.
  - التوكل على الله.
  - الأمل.
  - التوبة.
  - قيم الأسرة.
  - الأخوة.
- التحقق من ذكر اسم السورة ورقم الآية عند إنشاء محتوى قرآني.
- التحقق من وجود مصدر عند إنشاء حديث.
- منع نسبة الأدعية أو الأقوال إلى النبي ﷺ دون مصدر موثوق.
- تنسيق المنشورات باستخدام Telegram HTML.
- إنشاء صور مناسبة اختيارياً عبر Pexels.
- إرسال النص وحده بأمان عند فشل Pexels أو عدم توفر صورة.
- تجنب تكرار الصور المنشورة.
- حفظ المنشورات في قاعدة بيانات SQLite.
- منع تكرار المحتوى نهائياً باستخدام بصمة رقمية.
- إنشاء نسخة احتياطية يومية من قاعدة البيانات.
- إعادة المحاولة تلقائياً عند فشل Telegram أو Groq، مع جعل إنشاء الصور اختيارياً حتى لا تتعطل دورة النشر.
- إرسال تنبيه إلى المدير عند فشل النشر.
- تسجيل الأحداث والأخطاء باستخدام Loguru.
- توفير نقطة فحص صحية لـ Railway على المسار `/health`.

## المتطلبات

- Python 3.12.
- حساب Telegram.
- بوت تم إنشاؤه من خلال BotFather.
- صلاحية المشرف للبوت داخل القناة.
- صلاحية نشر الصور في القناة.
- مفتاح Groq API.

## التثبيت محلياً

استنسخ المشروع من GitHub:

```bash
git clone https://github.com/JEOR89JINA/Rihanna_almohajira.git
cd Rihanna_almohajira
```

أنشئ بيئة Python افتراضية:

```bash
python -m venv .venv
```

فعّل البيئة الافتراضية:

على Linux وmacOS:

```bash
source .venv/bin/activate
```

على Windows:

```bash
.venv\Scripts\activate
```

ثبّت المكتبات:

```bash
pip install -r requirements.txt
```

أنشئ ملف البيئة:

```bash
cp .env.example .env
```

على Windows يمكن نسخ الملف يدوياً باسم `.env`.

بعد ذلك افتح ملف `.env` وأضف المفاتيح المطلوبة.

## متغيرات البيئة

| المتغير | مطلوب | القيمة الافتراضية | الاستخدام |
| --- | --- | --- | --- |
| `BOT_TOKEN` | نعم | — | رمز بوت Telegram من BotFather |
| `GROQ_API_KEY` | نعم | — | مفتاح Groq API |
| `CHANNEL_USERNAME` | لا | `@Athar_Dz_Islamic` | اسم القناة أو معرّفها الرقمي |
| `ADMIN_ID` | لا | `6856665810` | معرّف حساب المدير في Telegram |
| `POST_INTERVAL_HOURS` | لا | `3` | عدد الساعات بين المنشورات العامة |
| `DZIRI_INTERVAL_HOURS` | لا | `2.5` | عدد الساعات بين المنشورات الدزايرية |
| `TIMEZONE` | لا | `Africa/Algiers` | المنطقة الزمنية للجدولة |
| `LOG_LEVEL` | لا | `INFO` | مستوى التسجيل |
| `DATABASE_PATH` | لا | `publisher.sqlite3` | مسار قاعدة البيانات |
| `IMAGES_PATH` | لا | `images` | مجلد الصور المحلية |
| `GROQ_MODEL` | لا | `llama-3.3-70b-versatile` | نموذج Groq المستخدم؛ إذا كان إعداد Railway قديماً فسيستخدم البوت نموذجاً بديلاً مدعوماً |
| `PORT` | لا | `8080` | منفذ فحص الصحة في Railway |

مثال ملف `.env`:

```env
BOT_TOKEN=ضع_رمز_البوت_هنا
GROQ_API_KEY=ضع_مفتاح_Groq_هنا
CHANNEL_USERNAME=@Athar_Dz_Islamic
ADMIN_ID=6856665810
POST_INTERVAL_HOURS=3
DZIRI_INTERVAL_HOURS=2.5
TIMEZONE=Africa/Algiers
LOG_LEVEL=INFO
DATABASE_PATH=publisher.sqlite3
IMAGES_PATH=images
GROQ_MODEL=llama-3.3-70b-versatile
PORT=8080
```

لا ترفع ملف `.env` إلى GitHub، ولا تشارك محتوياته مع أي شخص.

## تشغيل البوت محلياً

```bash
python bot.py
```

عند التشغيل سيقوم البوت بالآتي:

1. الاتصال بقاعدة البيانات.
2. تشغيل خادم فحص الصحة.
3. تشغيل الجدولة.
4. إنشاء أول منشور ونشره مباشرة.
5. تكرار المنشورات العامة كل 3 ساعات والمحتوى الدزايري كل ساعتين ونصف، مع تذكير قيام الليل يومياً عند 2:00 فجراً.
6. إرسال رسالة تشغيل إلى المدير.

لإيقاف البوت محلياً اضغط:

```text
Ctrl + C
```

## أوامر المدير

الأوامر التالية متاحة فقط للحساب الذي يطابق قيمة `ADMIN_ID`:

| الأمر | الوظيفة |
| --- | --- |
| `/start` | عرض رسالة تشغيل البوت |
| `/help` | عرض قائمة الأوامر |
| `/status` | عرض حالة البوت وموعد النشر القادم |
| `/stats` | عرض عدد المنشورات الكلي وعدد منشورات اليوم |
| `/publish` | إنشاء ونشر منشور فوراً |
| `/pause` | إيقاف النشر التلقائي مؤقتاً |
| `/resume` | استئناف النشر التلقائي |
| `/test` | إنشاء معاينة دون نشرها في القناة |
| `/logs` | عرض آخر سجلات التشغيل |

## إعداد البوت والقناة

1. افتح BotFather في Telegram.
2. أنشئ بوتاً جديداً أو استخدم بوتك الحالي.
3. انسخ `BOT_TOKEN` إلى ملف `.env`.
4. أضف البوت مشرفاً في قناة `@Athar_Dz_Islamic`.
5. فعّل للبوت صلاحية نشر الصور والمنشورات.
6. تأكد من أن `ADMIN_ID` هو معرّف حسابك الصحيح في Telegram.

إذا لم يرد البوت على `/start` أو `/test`، فتحقق من أن الخدمة تعمل وأن رمز البوت صحيح.

## النشر على Railway

### 1. رفع المشروع إلى GitHub

```bash
git add .
git commit -m "Add Arabic README"
git push origin main
```

### 2. إنشاء خدمة في Railway

1. افتح Railway.
2. أنشئ مشروعاً جديداً.
3. اختر النشر من GitHub.
4. اختر المستودع:
   `JEOR89JINA/Rihanna_almohajira`
5. انتظر حتى تنتهي عملية البناء.

يحتوي المشروع على ملفات Railway التالية:

- `railway.json`
- `Dockerfile`
- `.dockerignore`
- `nixpacks.toml`
- `runtime.txt`
- `Procfile`

وسيتم تشغيل البوت بالأمر:

```bash
python bot.py
```

### 3. إضافة المتغيرات في Railway

من قسم **Variables** في Railway، أضف:

```env
BOT_TOKEN=...
GROQ_API_KEY=...
CHANNEL_USERNAME=@Athar_Dz_Islamic
ADMIN_ID=6856665810
POST_INTERVAL_HOURS=3
DZIRI_INTERVAL_HOURS=2.5
TIMEZONE=Africa/Algiers
LOG_LEVEL=INFO
```

لا تضع المفاتيح السرية داخل ملفات المشروع أو داخل GitHub.

### 4. التخزين الدائم

يستخدم البوت SQLite لحفظ المنشورات ومنع التكرار. وللحفاظ على قاعدة البيانات والصور والسجلات بعد إعادة إنشاء خدمة Railway، يُفضل إضافة **Volume** وربطه بمجلد المشروع.

بدون تخزين دائم سيعمل البوت، لكن قد تُحذف قاعدة البيانات المحلية عند إعادة إنشاء الخدمة، مما قد يسمح بتكرار منشورات سابقة.
