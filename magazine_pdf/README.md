# مجلد المجلة — magazine_pdf

ضع جميع ملفات PDF الخاصة بالمجلة داخل هذا المجلد.

يدعم البوت وجود أكثر من ملف PDF هنا، وسيقوم تلقائيًا بفحص جميع الملفات
بصيغة `.pdf` وترتيبها حسب الاسم ثم نشر صفحاتها واحدة تلو الأخرى بدون تكرار.

## مثال على الترتيب

```
magazine_pdf/
    magazine_issue_5.pdf
    magazine_issue_6.pdf
    special_edition.pdf
```

## ملاحظات

- لا تضع ملفات غير PDF داخل هذا المجلد.
- إذا أضفت إصدارًا جديدًا، فقط ضع الملف هنا وأعد تشغيل البوت؛
  سيكتشفه تلقائيًا ويبدأ بنشر صفحاته الجديدة (التي لم يسبق نشرها).
- يتم تمييز كل صفحة ببصمة SHA-256 لمحتوى الصورة، لذا حتى لو تغيّر
  اسم الملف أو ترتيبه، لن تُنشر نفس الصفحة مرتين.
